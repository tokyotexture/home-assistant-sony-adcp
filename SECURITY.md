# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's
private vulnerability reporting feature for this repository.

Include the affected version, impact, reproduction steps, and any suggested
mitigation. Do not include real projector passwords or Home Assistant secrets.

## Network security

Sony ADCP is a local protocol and is not encrypted. Keep projectors and Home
Assistant on a trusted network, restrict network access to the ADCP port, and
do not expose the projector directly to the internet.
